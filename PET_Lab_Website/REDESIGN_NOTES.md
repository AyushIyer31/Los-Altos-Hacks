# PET Lab redesign

This folder contains the redesigned static PET Lab website.

## Highlights

- Image-led molecular hero using the supplied artwork and corrected PET Lab logo
- Strict black-and-white editorial design system with a true light/dark inversion
- About/mission section directly after the hero
- Responsive navigation for desktop, laptop, and mobile
- Restyled protein library, enzyme design workflow, results report, team profiles, and footer without colored startup-style UI effects
- Removed parallax, card tilts, word-by-word heading motion, gradients, glow, and other decorative effects
- Updated logo loading animation and improved Tapasvi Reddy Marreddi portrait crop
- Existing PDB data, optimization calls, charts, and 3D result views preserved

## Preview

Serve this directory with any static web server, or deploy it using the included `netlify.toml` configuration.

The optimization service is configured to use the existing production API outside `localhost`.
